## Features
- **Contract Customizer** - Generate air-tight service agreements tailored to your specific creative or technical field.
- **Payment Protection** - Automatically includes clauses to prevent scope creep and ensure timely payments.
- **IP Protection** - Clear, enforceable language to define exactly who owns what at every stage of the project.
- **Simplified Disputes** - Practical guidance and templates for handling client disagreements professionally.

## Installation
```bash
npm install
```

## Quick Start
```bash
npm run dev
```

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS
- **State Management**: React Hooks & Context API
- **Design**: Shadcn UI / Lucide Icons

> [!TIP]
> Use the "Scope Guard" feature while drafting to automatically flag potential scope creep in client-provided briefs.
